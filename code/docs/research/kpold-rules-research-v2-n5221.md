### RULE 2: kpold-237-protaseis-taktiki (ΚΠολΔ 237§1)

**Νέες ρυθμίσεις:**
- 90 ημέρες για ημεδαπούς: **ΔΙΑΤΗΡΕΙΤΑΙ**
- 120 ημέρες για αλλοδαπούς: **ΝΕΟ** — στην v1 spec δεν υπήρχε αυτή η ρητή πρόβλεψη για ξένα
- Η 90ήμερη **δεν αναστέλλεται** κατά τη διαδικασία διαμεσολάβησης (Ν. 5221/2025 + Ν. 5282/2026)

- Αφαιρέθηκαν από 237 οι διατάξεις περί οψιγενών ισχυρισμών — μεταφέρθηκαν σε νέο άρθρο 269

**Αφετηρία:** Διατηρείται: λήξη προθεσμίας επίδοσης αγωγής (215§2)

**Patch required:** Προσθήκη `duration_foreign: { value: 120, unit: "days" }` + `mediation_does_not_suspend: true`
